2026-11-04，用户已明确选择以下差异，不需要再次确认：

| 项目 | l0yce/douyin-bot | 本项目当前选择 |
| --- | --- | --- |
| 收发 | Playwright/Firefox 网页版 | 同一路线，专用持久资料目录，常规无界面运行 |
| 登录 | 浏览器登录态 | 用户手动登录及验证码操作，不自动登录 |

浏览器页面选择器、身份核验和气泡读取取自用户提供的参考代码，保留 AGPL-3.0 许可与说明，见根目录 THIRD_PARTY_NOTICES.md。调度、持久队列和单次发送由本项目实现，不调用上游发送失败后再按 Enter 的回退路径。

网页气泡提供平台消息 ID 时保留；没有 ID 时保留空值，本地哈希仅用于观测连续性。消息上下文含方向、类型、平台 ID、时间和待回复标记，截断至配置字符预算。历史中包含真实己方消息；尚未处理的新来信不会伪装成历史。媒体只标记类型，不声称看过。

未迁移 example 的 Node 桥接、Web 管理面板、Linux systemd 部署与媒体视觉理解。当前范围仍是本机 Python 白名单私聊文字。原有小时/日配额、暂停文件、未决发送阻断和原生历史回执继续保留。新增运行时长期记忆未启用。

冷启动必须等待页面登录状态及会话列表渲染；选择联系人必须通过 sec_uid 和抖音号核验，昵称只用来定位。临时读取失败重试，连续失败恢复浏览器；历史无法连续对齐时保留检查点等待，不把加载的旧消息当新来信。不确定的发送不会自动重试。
